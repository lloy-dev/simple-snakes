## Setup

1. Download a PICO-8 cartridge. You can get either the `.p8` file or the `.p8.png` image.
2. Use the free [Education Edition website](https://www.pico-8-edu.com/) if you haven't acquired a license yet.
3. Click on the play button and a console-like display should appear.
4. Enter `load` and upload the `.p8` or `.p8.png` file.
5. Enter `run` or press **CTRL + R** to run the cartridge. Have fun!
